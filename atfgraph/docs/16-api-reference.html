    Python API reference

    This page lists every public name exported by atfgraph (atfgraph.__all__, version 0.3.0.dev0), grouped by what it is for, with its public methods and a one-line purpose. It is a lookup table generated from the installed package and checked against python/atfgraph/; the numbered guides explain how to use each group. async marks coroutine methods; names in the same row separated by / are retained aliases of one object.

    Errors

    NameRaised when
    ATFGraphErrorBase class for every SDK error
    APIErrorThe graph server answered with an error envelope (status, code, message)
    AuthError401 or 403
    NotFoundError404
    ConflictError409: immutable definition changed, stale lease, revision mismatch
    ValidationError400 or 422
    TransportErrorThe HTTP request never produced a response
    TraversalErrorA traverser reached a terminal state other than succeeded; subclasses TraversalFailed, TraversalCancelled, TraversalTimedOut
    WaitTimeoutThe client-side wait deadline passed before a terminal state
    HandlerError(message, *, code="handler_error", retryable=False), RetryableError(message, *, code="retryable")Raised from a handler to control the error envelope (to_envelope()); RetryableError is the retryable shorthand
    LeaseLostThe worker no longer holds the lease for a task
    NoExecutionContextA context-bound operation was used outside a worker task
    ModelNotConfiguredapp.ai was called without a configured model provider
    ModelError, MediaError, MediaCapabilityError, MediaProviderNotConfiguredProvider answered badly; media payload unusable; provider cannot do what was asked (no request sent); missing media API key
    EmbeddingError, SemanticIndexErrorEmbedding provider failed; lexical write succeeded but vector indexing did not finish
    RateLimitExceeded, TransformError, RealtimeError, SessionTransportError, ServerlessEventError, ServerlessLoadError, HarnessFailureListed with their groups above
