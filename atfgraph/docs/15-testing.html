    Testing against the graph server

    At the end of this page you can write a pytest that starts a real atfgraphd on a random loopback port with its own temporary SQLite file, serves your agent node in the same process, submits traversers and asserts on results, paths and the event log, and tears everything down. This is how the repository tests itself (tests/test_integration.py), and it is the way to test a node. A short final section covers atfgraph.testing.FakeGraphServer, an in-memory double for pure SDK logic.

    Prerequisites: a built graph server (cargo build --bins at the root of the checkout; the tests find target/debug/atfgraphd, or set ATFGRAPH_TEST_BINARY / ATFGRAPH_TEST_CLI), pytest and pytest-asyncio (python -m pip install './python[test]'), and httpx, which the SDK already depends on.

    The daemon fixture

    The fixture spawns the binary, waits for its readiness line on stderr, probes /health, yields the base URL and terminates the process. Adapted from tests/test_integration.py:

    import contextlib
import os
import re
import select
import subprocess
import time
from pathlib import Path

import httpx

ROOT = Path(__file__).resolve().parents[1]
BINARY = ROOT / "target/debug/atfgraphd"


@contextlib.contextmanager
def daemon(tmp_path: Path, *, lease_seconds: int = 2, extra_env=None):
    assert BINARY.exists(), "Build the actual daemon with cargo build --bins first"
    tmp_path.mkdir(parents=True, exist_ok=True)
    env = {k: v for k, v in os.environ.items() if not k.startswith("ATFGRAPH_")}
    env.update(ATFGRAPH_LEASE_SECONDS=str(lease_seconds))
    env.update(extra_env or {})
    process = subprocess.Popen(
        [str(BINARY), "--listen", "127.0.0.1:0", "--database-url", f"sqlite://{tmp_path / 'graph.db'}?mode=rwc"],
        cwd=ROOT, env=env, stdout=subprocess.DEVNULL, stderr=subprocess.PIPE, text=True,
    )
    try:
        deadline = time.monotonic() + 15
        url = None
        lines = []
        while time.monotonic() < deadline:
            if process.poll() is not None:
                raise AssertionError("Daemon exited: " + "".join(lines) + process.stderr.read())
            ready, _, _ = select.select([process.stderr], [], [], 0.2)
            if ready:
                line = process.stderr.readline()
                lines.append(line)
                found = re.search(r"API (http://[^/]+)/api/v2", line)
                if found:
                    url = found.group(1)
                    break
        assert url, "Daemon did not announce readiness: " + "".join(lines)
        with httpx.Client(base_url=url, timeout=5) as client:
            assert client.get("/health").json()["product"] == "ATFGraph vNext"
        yield url
    finally:
        process.terminate()
        try:
            process.wait(timeout=8)
        except subprocess.TimeoutExpired:
            process.kill()
            process.wait(timeout=5)
        process.stderr.close()

    Points that matter:

    ChoiceWhy
    --listen 127.0.0.1:0The kernel picks a free port; the base URL is read from the API <base>/api/v2 readiness line on stderr
    --database-url sqlite://<tmp>/graph.db?mode=rwcOne fresh database per test; nothing shared, nothing to clean
    ATFGRAPH_* stripped from the environmentYour shell's server, key and model settings cannot leak into the test
    ATFGRAPH_LEASE_SECONDSShort leases make lease-expiry and retry tests fast; raise it (lease_seconds=30) for slow handlers
    extra_envPass {"ATFGRAPH_CONFIG_FILE": ...} for an authenticated daemon (see below)

    The same database directory can be reused across two daemon(...) blocks to test that memory survives a restart, which tests/test_integration.py does.

    Serve the node in-process

    Bind the agent to a Client for the daemon, start app.serve as a task, wait until the worker has enrolled, then submit through the client. Adapted from tests/test_integration.py:

    import asyncio

import pytest

from atfgraph import Agent, Client
from test_integration import daemon


@pytest.mark.asyncio
async def test_python_worker_nested_call_at_capacity_one(tmp_path):
    with daemon(tmp_path, lease_seconds=5) as url:
        async with Client(url) as client:
            agent = Agent(node_id="nested", client=client, capacity=1)

            @agent.skill()
            async def leaf(value: int) -> dict:
                await agent.memory.set("last", value, scope="session")
                return {"value": value + 1}

            @agent.traversal()
            async def parent(value: int) -> dict:
                return await agent.traverse("nested.leaf", value=value)

            stop = asyncio.Event()
            serving = asyncio.create_task(agent.serve(stop=stop))
            try:
                for _ in range(100):
                    if agent.worker and agent.worker.worker_id:
                        break
                    if serving.done():
                        await serving
                    await asyncio.sleep(0.02)
                session = await client.create_session()
                handle = await client.submit("nested.parent", {"value": 4}, session_id=session)
                assert await handle.result(timeout=12) == {"value": 5}
                path = await handle.path()
                assert len(path.items) == 2
                assert await agent.memory.session(session).get("last") == 4
            finally:
                stop.set()
                try:
                    await asyncio.wait_for(serving, 5)
                except asyncio.TimeoutError:
                    serving.cancel()
                    await asyncio.gather(serving, return_exceptions=True)

    The pytest.ini at the checkout root sets asyncio_mode = auto and pythonpath = python, so from test_integration import daemon works from any file under tests/ and async def tests need no extra marker. The enrolment loop is the only synchronisation you need: agent.worker.worker_id is set once the worker has registered and enrolled, and awaiting serving early surfaces registration errors instead of a timeout. For an example module, app.bind_client(client) binds the already-constructed agent, as tests/test_migrated_retrieval_examples.py does. The serving() helper in tests/test_feature_examples_extended.py wraps this loop in an asynccontextmanager.

    Assert on traversers, paths and the event log

    Everything the graph server recorded is reachable through the client:

    • await handle.result(timeout=...) returns the output or raises TraversalFailed, TraversalCancelled or TraversalTimedOut.
    • await client.get(traverser_id) returns a TraverserResult with status, output and error; poll it for a status such as waiting (the until() helper in tests/test_runtime_journeys.py).
    • await handle.path() returns the Path; len(path.items) counts steps, and step.target / step.raw["version"] show which version served each step (tests/test_discovery_identity.py).
    • await client.event_log(traverser_id) returns the persistent events; progress events carry event.type == "progress" and event.data["data"]. Adapted from tests/test_sdk_extension_integration.py:
    from atfgraph import Client


async def usage_models(client: Client, traverser_id: str) -> list:
    journal = await client.event_log(traverser_id)
    usage_events = [
        event.data["data"] for event in journal
        if event.type == "progress" and "usage" in (event.data.get("data") or {})
    ]
    return [event["usage"]["model"] for event in usage_events]

    Worker-side facts are visible too: the credentials, usage and node-log tests in tests/test_sdk_extension_integration.py and tests/test_credentials_sdk.py follow the same shape and then read back through app.observability and app.credentials.

    Example fixture modes

    Every shipped example that calls a model or an embedding provider has a fixture mode, so the retrieval and research examples run on a real daemon with nothing configured. Adapted from tests/test_migrated_retrieval_examples.py:

    import asyncio
import importlib

import pytest

from atfgraph import Client
from test_integration import daemon


@pytest.mark.asyncio
async def test_retrieval_basics_journey(tmp_path, monkeypatch):
    monkeypatch.setenv("EXAMPLE_MODE", "fixture")
    module = importlib.import_module("examples.python.retrieval_basics.main")
    app = module.app
    with daemon(tmp_path / "retrieval_basics", lease_seconds=30) as url:
        async with Client(url) as client:
            app.bind_client(client)
            stop = asyncio.Event()
            worker = asyncio.create_task(app.serve(stop=stop, capacity=16))
            try:
                for _ in range(500):
                    if app.worker and app.worker.worker_id:
                        break
                    await asyncio.sleep(0.01)
                result = await client.traverse("retrieval_basics.ingest_document", {"document_id": "desk", "text": "The travel desk opens at 9am."}, timeout=60)
                assert result["vectors"] > 0
                answer = await client.traverse("retrieval_basics.answer_question", {"question": "When does the travel desk open?"}, timeout=60)
                assert "9am" in answer["answer"] and answer["citations"]
            finally:
                stop.set()
                await asyncio.wait_for(worker, 15)

    examples/python/retrieval_basics/support.py reads EXAMPLE_MODE (default fixture; anything other than fixture or live raises ValueError). In fixture mode embeddings come from a deterministic token hash and a model call raises ValueError("model calls require EXAMPLE_MODE=live"); in live mode a missing ATFGRAPH_EMBEDDING_URL/ATFGRAPH_EMBEDDING_MODEL or ATFGRAPH_MODEL_URL/ATFGRAPH_MODEL_NAME raises instead of falling back. The resilience examples use a local fixture model server (examples/python/features/resilience/fixture_model.py) the same way.

    Authenticated daemons

    To test roles and namespaces, write a configuration file and hand it to the daemon through extra_env. Adapted from tests/test_discovery_identity.py:

    from pathlib import Path


def config(path: Path) -> dict:
    path.write_text(
        "atfgraph:\n"
        "  auth:\n"
        "    tokens:\n"
        "      - {token: discovery-admin, namespace: travel, principal: alice, roles: [admin]}\n"
        "      - {token: discovery-worker, namespace: travel, principal: runner, roles: [worker, invoke]}\n"
        "      - {token: discovery-reader, namespace: travel, principal: alice, roles: [invoke]}\n"
    )
    return {"ATFGRAPH_CONFIG_FILE": str(path)}

    Then with daemon(tmp_path / "db", extra_env=config(tmp_path / "config.yaml")) as url: and Client(url, api_key="discovery-admin"). Roles seen in the tests are admin, worker and invoke; examples/python/features/access_boundaries/config.example.yaml is a complete file of this kind.

    Evaluation sets: cases, assertions, scores across versions

    Unit tests prove a handler; an evaluation set proves a capability version against the inputs that matter to you, and keeps the score. A case set belongs to one target (label.capability). Each case is an input plus assertions on the recorded run; an eval run admits one real traverser per case, and the graph server settles each result from the traverser's status, output, error, duration and recorded usage. Scores are grouped by the version each run executed against, so a regression shows up as a pass rate that moved between versions.

    from atfgraph import Client, Evals
from atfgraph.evals import contains, exists, max_duration_ms, status

async def main():
    async with Client("http://127.0.0.1:18880") as client:
        evals = Evals.for_client(client)          # or app.evals inside a node
        case_set = await evals.create_set("intake regressions", "co-consult.consult", description="free-text intake must extract the route")
        await evals.add_case(
            case_set.id, "bne-bali-3-nights",
            {"request": "plan trip BNE to Bali 23 Oct 3 days, 2 adults"},
            assertions=[status("succeeded"), exists("brief.destination"), contains("brief.destination", "Bali"), max_duration_ms(60_000)],
            tags=["intake"],
        )
        await evals.add_case(case_set.id, "refuses nonsense", {"request": ""}, assertions=[status("failed")])

        run = await evals.run(case_set.id, version="0.3.0", label="pre-release")
        detail = await evals.wait(run.id, timeout=300)
        for result in detail.results:
            print(result.case_name, result.status, [f.message for f in result.failures])
        for score in await evals.scores(case_set.id):
            print(score.version, score.pass_rate, score.duration_ms_p50, score.cost_usd)

    Assertion types: equals, not_equals, contains, not_contains, regex, exists, type, schema (JSON Schema), status, error_code, max_duration_ms, max_cost_usd, max_tokens, min_length, max_length. path addresses the traverser output (brief.destination, items[0].name; empty for the whole output). A case with no assertions asserts status: succeeded. A traverser that fails when no assertion expected a failure is recorded as errored, not failed, so a broken worker is distinguishable from a wrong answer.

    The same data is in the console under Evaluate → Evaluations (case sets, runs with per-assertion results, scores by version), and over HTTP under /api/v2/evals/* (../api.md). Runs, results and scores are owned by the principal that created the set; admins see every set in the namespace.

    FakeGraphServer: a fast contract double

    atfgraph.testing.FakeGraphServer is an in-memory double of the /api/v2 contract served through httpx.MockTransport. It exists for fast unit tests of SDK logic; the Rust graph server is the product and the fixture above is how you test a node. Adapted from tests/python_test_examples.py:

    import pytest

from atfgraph import TraversalFailed
from atfgraph.testing import FakeGraphServer, serve_agent
from examples.python.first_node.agent import app as hello


async def test_first_node_greets():
    server = FakeGraphServer()
    async with serve_agent(hello, server, capacity=1):
        client = server.client()
        result = await client.traverse("hello.greet", {"name": "Ada"}, timeout=10)
        assert result["greeting"] == "Hello Ada!"
        with pytest.raises(TraversalFailed, match="must not be empty"):
            await client.traverse("hello.greet", {"name": "  "}, timeout=10)
        await client.aclose()

    What it covers (python/atfgraph/testing.py): agents, sessions, traversers with nested children, operation and idempotency keys, cancel propagation, retries, lease expiry and timeouts, the event log as an SSE snapshot, scoped memory with revisions and TTL, and the worker protocol. server.advance(seconds) moves its clock, server.fail_next(path_suffix, status=500) injects failures, server.records(target=...) inspects attempts. Its limits: it has no knowledge, usage, log, run-metadata, credential, identity or access routes (tests/test_mlflow_tracing.py relies on the missing metadata route to test graceful failure), its authentication is an optional api_keys map from token to a small atfgraph.testing.Identity of namespace, principal and roles (everything is allowed when the map is empty), and it is not the reference implementation. Anything you prove against it still needs a run against atfgraphd.
