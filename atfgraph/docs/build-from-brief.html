    Describe what you want to build

    ATFGraph vNext supports Python authoring and two distinct skill concepts. Builder skills guide Claude Code or Codex to create an application. Runtime skills are deterministic Python functions exposed by that application; traversals can coordinate those functions and other agent nodes.

    The bundled skills target the vNext runtime only: atfgraph-vnext (build a project from a brief), atfgraph-vnext-use (offload work to registered nodes), atfgraph-vnext-personal (install a node on this machine) and atfgraph-vnext-topology (design the graph without building). The installer adds all four and refuses to overwrite existing directories unless --replace is explicit. It does not replace the installed atfgraph skill used with the current server.

    Install for Claude Code

    From this repository's root (or from an installed client, whose share/atfgraph/resources/skills holds the same files), install into a new name:

    python3 scripts/install-skills.py --harness claude
export SDK_ROOT="$PWD"                              # this checkout
export SERVER_ROOT="$PWD"                           # the same checkout holds the server, if you run one locally

    Start Claude Code in the intended project directory, then request the atfgraph-vnext skill by name. If that destination already exists, review it before replacing it; the commands above are intended for a first installation.

    Install for Codex

    From the same directory:

    python3 scripts/install-skills.py --harness codex
export SDK_ROOT="$PWD"
export SERVER_ROOT="$PWD"

    Start a new Codex session and invoke $atfgraph-vnext. The skill guides the coding assistant through authoring, testing and deployment.

    Give it a brief

    Build an AI travel consultant that understands a brief, clarifies missing details, and creates a travel plan with flights, accommodation and activities. Keep the traveller's brief, saved offers and latest proposal in session memory. Explain the recommendations and answer follow-ups about fares and alternative hotels from saved evidence. Refresh searches only when needed or explicitly requested. Include offline tests, Python client and CLI examples, and prepare Docker Compose deployment.

    The coding assistant should produce a real project, run its tests and demonstrate a traverser and its recorded path. Configuring providers for live results is separate from the fixture demonstration. A package is not a hosted service until a deployment starts healthy workers.

    Continue with Python authoring to extend the generated node, or CLI and deployment usage to install, invoke and host it.
