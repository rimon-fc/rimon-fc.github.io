    createEvalCaseSet

    POST /api/v2/evals/case-sets

    Requires: invoke role

    Create a case set for one `label.capability` target, optionally with its first cases (at most 500). version pins an immutable agent version; absent or empty means the newest registered version at run time. The set belongs to the calling principal: admins see every set in the namespace, other callers only their own, and foreign ids answer 404 eval_set_not_found. Namespaces hold at most 1024 sets; names are at most 256 characters, descriptions 4096.

    startEvalRun

    POST /api/v2/evals/case-sets/{id}/run

    Requires: invoke role

    Start a run of the set (or of case_ids) against the requested version, the set's version, or the newest registered version, in that order of preference; the resolved immutable version is recorded on the run. The agent and capability are resolved before anything is written (404 agent_not_found / capability_not_found). Then one root traverser per case is admitted through the ordinary submit path with idempotency key `eval:<run_id>:<case_id>`, so access policies, capacity and the worker protocol apply unchanged; an admission fault marks that case errored immediately. Returns 202 with the run in status running; poll getEvalRun, or read the traversers directly.
