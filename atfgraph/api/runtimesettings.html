    RuntimeSettings operations

    Stored runtime documents per namespace: list, read, write and delete a key, then apply it to the running process. Saving a document and applying it are separate steps.

    Operations

    OperationMethodPath
    listRuntimeSettingsGET/api/v2/runtime/settings
    getRuntimeSettingsGET/api/v2/runtime/settings/{key}
    putRuntimeSettingsPUT/api/v2/runtime/settings/{key}
    deleteRuntimeSettingsDELETE/api/v2/runtime/settings/{key}
    applyRuntimeSettingsPOST/api/v2/runtime/settings/{key}/apply
