    memoryChanges

    POST /api/v2/memory/changes

    Requires: invoke role, worker role

    Read the durable namespace change feed after a signed-range sequence cursor. With standalone invoke permission, omit scope to receive authorized global, actor, session and workflow entries; admins see the namespace. Worker-only credentials require an active lease and see only global, inherited actor, bound session and workflow entries. Supply scope and context to restrict further. next_cursor advances across filtered rows up to a consistent snapshot high-water mark. Value sets include value up to 65536 canonical bytes, otherwise value_omitted. Entries older than 30 days are pruned opportunistically; a positive cursor older than retained history returns cursor_expired (409), and a cursor below oldest_sequence means events were pruned and the reader has a gap. Resnapshot and restart with after=0. TTL expiry does not emit an event.

    listMemory

    POST /api/v2/memory/list

    Requires: invoke role, worker role

    Page one scope's live keys in ascending key order. scope is required and resolves ownership exactly like memory/read: same id fields, same worker lease authority, same fault codes. Deleted tombstones and expired TTL rows are excluded. kind selects the value or vector store; value entries carry expires_at, vector entries carry dimension. Pass the returned next_cursor back as cursor; a null next_cursor is the last page. Cursors are the last key of the page, so keys inserted before the cursor are not revisited.

    searchMemoryVectors

    POST /api/v2/memory/vector/search

    Requires: invoke role, worker role

    Cosine similarity search within one scope. The linear strategy scores source vectors exactly. The hnsw strategy uses migrated PostgreSQL vector indexes and merges source vectors that are not yet backfilled; approximate index recall depends on the corpus. SQLite and PostgreSQL without an applicable index use linear search. Vectors of another dimension are ignored, and scanned reports how many were compared. filters are exact-match on top-level metadata keys under JSON equality (at most 32 keys). Results are ordered by score descending then key ascending and truncated to top_k.

    setMemoryVector

    POST /api/v2/memory/vector/set

    Requires: invoke role, worker role

    Store or replace one embedding under a scoped key. Every element must be a finite number and the norm must be non-zero and at most 1e150; otherwise invalid_vector (400). metadata must be a JSON object of at most 16384 canonical bytes, otherwise invalid_metadata (400). expected_revision is compare-and-set against the live revision (0 means the key must not exist) and mismatches return revision_conflict (409). Revisions never move backwards across a delete.
