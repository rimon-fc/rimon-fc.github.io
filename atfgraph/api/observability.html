    appendLogs

    POST /api/v2/logs

    Requires: worker role

    Ship bounded node log lines for the executing attempt (worker lease or admin traverser_id, as for usage). Ingestion is opt-in per namespace: 409 node_logs_disabled until an admin enables it through observability settings. Messages are cut to the namespace byte bound on a character boundary and counted in truncated; sequences are gap-free per namespace. Lines older than the retention period are pruned opportunistically.

Deliveries carry x-atfgraph-event, x-atfgraph-delivery, x-atfgraph-attempt, x-atfgraph-timestamp and, when a secret is present, x-atfgraph-signature `sha256=<hex>` over the body.

    recordUsage

    POST /api/v2/usage

    Requires: worker role

    Record model or media calls of the attempt the caller is executing. Workers pass task_id (or step_id) + lease_token; the root tree is locked and the lease re-read before the write (409 parent_lease_invalid on a stale or cancelled lease, 403 lease_required without one). Admins may backfill with traverser_id. Provide entries (1-100) or a single entry. The same (traverser, attempt, call_id) is deduplicated and reported in items; without call_id the server assigns one and never deduplicates. cost_usd is stored only when supplied so unknown prices stay distinct from zero. Rows of failed attempts are retained. Committed writes fan out usage.recorded to the namespace webhook.

    usageTotals

    GET /api/v2/usage/totals

    Requires: invoke role

    Aggregate usage over the caller's own runs in [since, until] (default: the last 30 days). Admins may pass principal or all_principals; other callers get 403 principal_forbidden. group_by buckets by run, model, provider, day, attempt_status, label, principal, capability or none. capability is the traversal or skill that made the call, so it answers per-decision questions across runs. At most 50000 rows are aggregated; truncated is true when more matched. cost_usd is null unless at least one call was priced.
