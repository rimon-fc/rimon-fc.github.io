    submitTraverser

    POST /api/v2/traversers

    Requires: invoke role

    Admit durable execution, pinned to the requested or resolved immutable version. Repeating an idempotency_key with identical payload returns the existing admission; different payload conflicts. Nested submissions require the active parent lease and inherit session and root. Session root turns serialize; children may execute concurrently. A realtime capability is a session entrypoint, not a traverser: submitting to it is refused with 400 realtime_entrypoint.
