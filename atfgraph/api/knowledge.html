    putKnowledgeDocument

    POST /api/v2/knowledge/put

    Requires: invoke role, worker role

    Write or replace one document in a memory scope. Provide exactly one of text (chunked server-side, optional chunk size/overlap) or chunks (1-2000 caller chunks). doc_id is 1-256 printable characters; text is at most 1 MiB, each chunk at most 32 KiB, metadata at most 16384 canonical bytes. expected_revision is compare-and-set (0 means must not exist; 409 revision_conflict). Scopes hold at most 20000 documents and 200000 chunks (422 scope_full). Writes do not append to the memory change feed.

    searchKnowledge

    POST /api/v2/knowledge/search

    Requires: invoke role, worker role

    Lexical BM25 search (k1 = 1.2, b = 0.75) over the chunks of one scope. Tokenisation lower-cases, splits camelCase and acronyms, and indexes ideographs per character; the same rules apply to queries. Results are ordered by score descending, then doc_id, then ordinal, identically on every page and process. filters are exact JSON equality against document metadata (at most 32 keys); doc_id restricts to one document; min_score floors the score. A query without indexable terms returns items:[] with terms:[] and status 200. There is no embedding index; use memory/vector for embeddings.
