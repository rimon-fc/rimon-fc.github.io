    Feature areas

    Each area is a tag in the contract. Counts, methods and roles come from the contract file; the one-line notes are editorial. An area listed here describes the published contract, not the state of a running deployment.

    Roles are the contract's own x-required-roles. Credentials carry a namespace and a principal; admin implies every role, and an operation marked "no credentials" is unauthenticated. A role is necessary, not sufficient: the server also enforces ownership.

    Generated route counts cover JSON request/response operations. The public Python SDK also provides Client.events(traverser_id) for SSE streaming and reconnection.

    Access

    Access policies and connector grants: who may start which traversals, and which external connectors a namespace may reach. Server authorization is authoritative; these operations edit the rules it enforces.

    • POST /api/v2/access/admit — admitAccess
    • GET /api/v2/access/connector — getOwnConnector
    • GET /api/v2/access/connectors — listConnectors
    • GET /api/v2/access/connectors/{principal} — getConnector
    • PUT /api/v2/access/connectors/{principal} — putConnector
    • POST /api/v2/access/connectors/{principal}/revoke — revokeConnector
    • POST /api/v2/access/evaluate — evaluateAccess
    • GET /api/v2/access/policies — listAccessPolicies
    • POST /api/v2/access/policies — createAccessPolicy
    • GET /api/v2/access/policies/{id} — getAccessPolicy
    • PATCH /api/v2/access/policies/{id} — updateAccessPolicy
    • DELETE /api/v2/access/policies/{id} — deleteAccessPolicy

    Admin

    Registering agent node definitions. Registration is immutable per version.

    • POST /api/v2/agents — registerAgent
    • DELETE /api/v2/agents/{label} — unregisterAgent

    Approvals

    Requesting a decision from a human or another principal while a traverser waits.

    • GET /api/v2/approvals — listApprovals
    • POST /api/v2/approvals — requestApproval
    • GET /api/v2/approvals/{id} — getApproval
    • POST /api/v2/approvals/{id}/decide — decideApproval
