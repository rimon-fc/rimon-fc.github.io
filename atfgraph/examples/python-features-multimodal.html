    README

    Rendered from examples/python/features/multimodal/README.md; the source file is not modified.

    Five traversals on one node, all fixture-tested without a live provider (tests/test_media_parity.py):

    TraversalSurfaceNotes
    describe(image_url, question)app.ai(text, Image.from_url(...), schema=Findings)image content part + structured output; Anthropic gets an image block, OpenAI-compatible gets image_url
    narrate(text, voice, model, format)app.ai_generate_audiotts-1 default; minimax/speech-*, fal-ai/..., openrouter/... by prefix; inline audio saved under ATFGRAPH_MEDIA_DIR
    transcribe(audio_b64, format, model)app.ai_transcribe_audiomultipart upload to /audio/transcriptions (whisper-1), or data: URL to fal-ai/whisper
    poster(prompt, model, size)app.ai_generate_imagedall-e-3/gpt-image-1, openrouter/google/..., fal-ai/flux/..., minimax/image-01; URL outputs are never downloaded implicitly
    narrate_stream(text)app.ai(..., stream=True)SSE deltas forwarded as app.note progress events

    Every call appends {"usage": {...}, "totals": {...}} to the traverser's event log; call.py prints them with UsageEvent.from_event. cost_usd is only what the provider reported (OpenRouter usage.cost); OpenAI, fal and MiniMax responses carry tokens or timings but no price, so total_cost_usd stays None and calls_without_price counts them.

    python -m atfgraph.worker --module examples.python.features.multimodal.agent:app
python -m examples.python.features.multimodal.call
