    README

    Rendered from examples/python/features/knowledge/README.md; the source file is not modified.

    One node, four traversals, no model provider. Everything is built from stored text and the server's BM25 ranking, so the example runs offline against a local daemon.

    TraversalSurfaceNotes
    ingest(documents)Knowledge.put_manyatomic batch; text is chunked server-side (1200 chars, 100 overlap), chunks keeps caller pages and per-chunk metadata
    ask(question, top_k, kind)Knowledge.searchBM25 hits with doc_id#ordinal citations; kind is an exact-match filter on document metadata; the answer is extractive with [n] markers
    catalog()Knowledge.stats, Knowledge.documentsscope statistics and a cursor-paginated listing
    forget(doc_id)Knowledge.deletetombstones the document and rewrites the index in the same transaction

    Knowledge lives in the node's global scope; use knowledge.scope("session") inside a traversal for per-session documents (the server binds it to the running task's session).

    python -m atfgraph.worker --module examples.python.features.knowledge.agent:app
python -m examples.python.features.knowledge.call

    call.py ingests the fixture documents in fixtures.py (invented travel-desk policy text), asks three questions, prints the catalog, deletes one document and shows the ranking change. Search results include chunk citations and lexical relevance scores. Use metadata filters to restrict the documents used for an answer.
