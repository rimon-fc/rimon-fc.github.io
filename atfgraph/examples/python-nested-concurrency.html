    Directory examples/python/nested_concurrency

    Agent node label fanout, version 1.0.0.

    Capabilities

    CapabilityKindSignatureModuleSummary
    fan_outtraversal(count: int = 6, batch: int = 3) -> dictexamples/python/nested_concurrency/agent.pySquare ``count`` numbers in batches of ``batch``, then run one retrying step.
    flaky_stepskill(succeed_on_attempt: int = 2) -> dictexamples/python/nested_concurrency/agent.pyFails with a retryable error until the server has scheduled ``succeed_on_attempt`` attempts.
    long_parenttraversal(seconds: float = 30) -> dictexamples/python/nested_concurrency/agent.pyA parent whose child sleeps; cancel the parent to see propagation.
    slow_stepskill(seconds: float) -> dictexamples/python/nested_concurrency/agent.pySleeps in small slices so a server cancel interrupts it promptly.
    squareskill(n: int) -> dictexamples/python/nested_concurrency/agent.py

    Non-default capability options: flaky_step: max_attempts=3; long_parent: timeout_seconds=600; slow_step: timeout_seconds=600
