    README

    Rendered from examples/python/research_path/README.md; the source file is not modified.

    Build a bounded research dependency graph, run independent searches concurrently, and synthesize dependent findings from saved citations. Live search supports Tavily and Parallel. Cycles, unknown dependencies and exceeded task budgets are rejected.

    Run locally

    From the atfgraph-vnext checkout, with its Python SDK installed in your active environment:

    atfg server start
EXAMPLE_MODE=fixture python -m atfgraph.worker --module examples.python.research_path.main:app
# In a second terminal:
python -m examples.python.research_path.call

    Or install and run the node as a managed local installation:

    atfg install ./examples/python/research_path
atfg run research_path

    The node.py entrypoint also works when this folder is copied out of the checkout. The graph server defaults to http://127.0.0.1:18880; inspect traversers and child calls at http://127.0.0.1:18880/ui/.

    Call with the CLI

    atfg traverse research_path.execute_deep_research --in '{"research_question": "How does vector retrieval work?", "max_depth": 1, "max_tasks_per_level": 2}'

    Providers

    EXAMPLE_MODE=fixture is the default: deterministic local example data and calculations, no model or search calls. Fixture scores demonstrate mechanics, not model quality.

    To use live model decisions, set EXAMPLE_MODE=live, ATFGRAPH_MODEL_URL, ATFGRAPH_MODEL_NAME and, when needed, ATFGRAPH_MODEL_API_KEY. Configure these before starting the worker. Missing settings fail explicitly; live failures never silently fall back to fixture answers.

    Python client

    from atfgraph import Client

async with Client("http://127.0.0.1:18880") as client:
    result = await client.traverse(
        "research_path.execute_deep_research",
        {'research_question': 'How does vector retrieval work?', 'max_depth': 1, 'max_tasks_per_level': 2},
        timeout=300,
    )
    print(result)

    For live research, choose SEARCH_PROVIDER=tavily with TAVILY_API_KEY, or SEARCH_PROVIDER=parallel with PARALLEL_API_KEY. TAVILY_SEARCH_URL and PARALLEL_MCP_URL override those provider endpoints for testing or a gateway. Search is bounded to five results per independent task; depth is 0–2 and tasks per depth 1–4. Dependent tasks reuse source evidence instead of issuing redundant searches. Fixture citations use fixture:// and do not represent web sources.
