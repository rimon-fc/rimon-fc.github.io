    README

    Rendered from examples/python/speech_notes/README.md; the source file is not modified.

    Run these commands from the atfgraph-vnext checkout. Install the authoring SDK and build the CLI once:

    python -m pip install -e ./python
cargo build --bin atfgraphd --bin atfg
export PATH="$PWD/target/debug:$PATH"
atfg server start

    The server defaults to http://127.0.0.1:18880; its browser UI is /ui/. Set ATFGRAPH_SERVER and ATFGRAPH_API_KEY for a different server.

    Start the worker, then exercise persistent text notes without a model:

    python -m atfgraph.worker --module examples.python.speech_notes.agent:app
# Another terminal:
python -m examples.python.speech_notes.call save_note '{"session_id":"notes-a","text":"Pack passports"}' --session notes-a
python -m examples.python.speech_notes.call read_note '{"session_id":"notes-a"}' --session notes-a

    For browser microphone dictation, configure OPENAI_API_KEY on the worker and optionally TRANSCRIPTION_MODEL (default whisper-1) before starting it. Then:

    python -m pip install aiohttp
python -m examples.python.speech_notes.web

    Open http://127.0.0.1:8041/, allow microphone access, record a short note and choose Stop and save. The local bridge forwards audio to transcribe_and_save; its transcript is saved by a recorded child call to save_note. Use the same session name to retrieve it. Provider and graph API credentials stay on the worker/bridge. This loopback bridge is a developer demo, not an authenticated public web service.

    The browser records WebM/Ogg/M4A and transcribes after stopping; it does not stream browser WebRTC audio directly to a provider. For realtime worker sessions, call speech-notes.voice with session_id, base64 PCM16 mono 24 kHz audio_b64, and transport (websocket, or webrtc with the optional aiortc dependency). Set REALTIME_MODEL if needed. The worker transcribes and invokes save_note; no unimplemented session decorator/handler is advertised. Microphone and live provider behavior require validation in your environment; local tests use explicit provider fixtures.
