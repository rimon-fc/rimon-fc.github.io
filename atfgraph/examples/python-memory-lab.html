    README

    Rendered from examples/python/memory_lab/README.md; the source file is not modified.

    Run these commands from the atfgraph-vnext checkout. Install the authoring SDK and build the CLI once:

    python -m pip install -e ./python
cargo build --bin atfgraphd --bin atfg
export PATH="$PWD/target/debug:$PATH"
atfg server start

    The server defaults to http://127.0.0.1:18880; its browser UI is /ui/. Set ATFGRAPH_SERVER and ATFGRAPH_API_KEY for a different server.

    python -m atfgraph.worker --module examples.python.memory_lab.agent:app
# Another terminal:
python -m examples.python.memory_lab.call remember '{"session_id":"demo-a","value":"first"}' --session demo-a
python -m examples.python.memory_lab.call remember '{"session_id":"demo-a","value":"second"}' --session demo-a
python -m examples.python.memory_lab.call vector_lookup '{"session_id":"demo-a"}' --session demo-a
atfg traverse memory-lab.emit_change --in '{"value":"changed"}'
atfg traverse memory-lab.recent_changes --in '{}'

    The second call returns previous: first; use demo-b in both places for an isolated session. Values and vectors persist on the graph server after the worker restarts. The fixed three-dimensional embeddings rank blue first without any model. The change subscription starts with the worker and polls the durable change feed. Its last 100 diagnostic events are process-local; poll recent_changes after a write. No provider credentials are needed.
