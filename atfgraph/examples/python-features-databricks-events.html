    README

    Rendered from examples/python/features/databricks_events/README.md; the source file is not modified.

    A second Python node that receives Databricks notification-destination events through a graph-server emitter and composes the Databricks integration node (integrations/databricks). It shows the intended shape:

    1. The graph server owns the emitter and authenticates the destination.
    2. databricks owns every Databricks call (Jobs API, SQL warehouse, AI Functions).
    3. incident_reviewer composes those capabilities with app.traverse and decides a rule-based verdict (incident, watch, no_action, needs_review).

    No model answer is fabricated. summarize_metric_change calls databricks.ai_query only when DATABRICKS_AI_ENDPOINT is set and otherwise reports review_skipped.

    Run (fixture mode, no workspace)

    From the atfgraph-vnext directory with a daemon running and DATABRICKS_WEBHOOK_SECRET set in the daemon's environment:

    DATABRICKS_FIXTURE_DIR=integrations/databricks/fixtures DATABRICKS_WAREHOUSE_ID=wh-fixture \
  python -m atfgraph.worker --module integrations.databricks.node.agent:app &
python -m atfgraph.worker --module examples.python.features.databricks_events.agent:app

    The reviewer logs its webhook URL (/hooks/{emitter_id}). Post a documented Databricks job notification to it:

    curl -X POST "$URL" -H "Authorization: Bearer $DATABRICKS_WEBHOOK_SECRET" \
  -H 'content-type: application/json' \
  --data @integrations/databricks/fixtures/jobs_on_failure.json

    The traverser output contains verdict: incident, failed_tasks: ["load"], the run's state message and the fixture metric rows, and the recorded path shows the two child steps on the databricks node.

    Emitter source

    DATABRICKS_TRIGGER_SOURCE defaults to generic_bearer (bridge: the destination sends Authorization: Bearer <secret>; the reviewer normalizes the raw payload). Set it to databricks once the root mounts that source (docs/databricks-integration-requests.md): the server then verifies Basic credentials, normalizes the event, deduplicates per run and event type, and applies the declared workspace_id / job_ids filters before admission.

    Test: tests/test_databricks_integration.py (real daemon, fixture Databricks).
