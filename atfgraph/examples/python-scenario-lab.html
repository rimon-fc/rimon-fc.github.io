    README

    Rendered from examples/python/scenario_lab/README.md; the source file is not modified.

    Generate synthetic entities, simulate decisions in bounded concurrent batches and aggregate outcome counts and percentages. Fixture populations are reproducible with a seed. All outcomes are synthetic, including live model decisions; they are not empirical observations.

    Run locally

    From the atfgraph-vnext checkout, with its Python SDK installed in your active environment:

    atfg server start
EXAMPLE_MODE=fixture python -m atfgraph.worker --module examples.python.scenario_lab.main:app
# In a second terminal:
python -m examples.python.scenario_lab.call

    Or install and run the node as a managed local installation:

    atfg install ./examples/python/scenario_lab
atfg run scenario_lab

    The node.py entrypoint also works when this folder is copied out of the checkout. The graph server defaults to http://127.0.0.1:18880; inspect traversers and child calls at http://127.0.0.1:18880/ui/.

    Call with the CLI

    atfg traverse scenario_lab.run_simulation --in '{"scenario": "Travellers choose budget or flexible fares", "population_size": 5, "parallel_batch_size": 2, "options": ["budget", "flexible"]}'

    Providers

    EXAMPLE_MODE=fixture is the default: deterministic local example data and calculations, no model or search calls. Fixture scores demonstrate mechanics, not model quality.

    To use live model decisions, set EXAMPLE_MODE=live, ATFGRAPH_MODEL_URL, ATFGRAPH_MODEL_NAME and, when needed, ATFGRAPH_MODEL_API_KEY. Configure these before starting the worker. Missing settings fail explicitly; live failures never silently fall back to fixture answers.

    Python client

    from atfgraph import Client

async with Client("http://127.0.0.1:18880") as client:
    result = await client.traverse(
        "scenario_lab.run_simulation",
        {'scenario': 'Travellers choose budget or flexible fares', 'population_size': 5, 'parallel_batch_size': 2, 'options': ['budget', 'flexible']},
        timeout=300,
    )
    print(result)
