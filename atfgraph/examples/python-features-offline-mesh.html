    README

    Rendered from examples/python/features/offline_mesh/README.md; the source file is not modified.

    Two ordinary Agent nodes, concierge and fares, hosted in one process by atfgraph.offline.OfflineMesh with no graph server. Verified by tests/test_offline_mesh.py.

    PieceWhat it shows
    OfflineMesh([concierge, fares])each node mounted as an ASGI sub-app at /{node_id} of one root ASGI app (/health, /nodes, /{node}/health, /{node}/definition, POST /{node}/capabilities/{name})
    mesh.invoke("concierge.plan", ..., session_id="trip-1")dispatch through the ASGI app; failures raise the usual TraversalFailed / TraversalCancelled / TraversalTimedOut
    await concierge.traverse("fares.quote", ...) inside the handlera nested child executed in-process by the other node, with its own task-local ExecutionContext (parent step, inherited root and session, real local lease)
    fares.memory.set(...) / concierge.memory.get(...)the mesh's in-memory store, scoped exactly as the SDK selects (session → workflow → global)
    record_usage + app.execution_cost()per-execution tracker, usage progress events, offline usage store, child usage propagated into the parent
    mesh.discoverythe normal AgentMesh facade over the offline registry
    mesh.submit(...) → Handlepoll, cancel, path(), event_log(), events() through mesh.client()

    The same concierge and fares objects run unchanged as outbound workers against a real graph server (python -m atfgraph.worker --module examples.python.features.offline_mesh.agent:concierge).

    What offline means here

    • The mesh never contacts a graph server and never claims or renews a remote lease. Leases are issued by the offline graph when a local execution starts and are checked on nested submits, progress, usage and checkpoints; a forged or stale lease is a 409, not a silent success.
    • Routes with no offline meaning (worker claim/renew, approvals, knowledge, vectors/search, publications, retention, ...) answer 501 offline_unsupported; mesh.graph.unsupported lists any that were hit.
    • Nothing is durable: state lives in mesh.graph for the life of the mesh.
    • Fares are a deterministic fixture; no supplier or model is called.
