    README

    Rendered from examples/benchmarks/scale_100k/README.md; the source file is not modified.

    Measure registration overhead and memory for large Python agent nodes. This is a synthetic local benchmark; its counts do not promise production throughput. Migrated from the parent benchmarks/100k-scale (renamed scale_100k so it is importable).

    From the atfgraph-vnext directory with the SDK installed:

    examples/benchmarks/scale_100k/run_benchmarks.sh --handlers 5000 --iterations 10 --warmup 2 --json
# or
python -m examples.benchmarks.scale_100k.python_bench.benchmark --handlers 5000 --output examples/benchmarks/scale_100k/results/ATFGraph_Python.json
python -m examples.benchmarks.scale_100k.analyze

    Start with a smaller handler count when checking setup (--handlers 500 --iterations 2 --warmup 1 --requests 2000 takes a few seconds). Compare runs on the same machine, toolchain and configuration, and keep the JSON output with your measurement notes. Historical comparison results from the original are not current SDK claims and were not carried over.

    What is measured

    MetricHow
    agent_init_time_*_msAgent(node_id, graph_server=...) alone; nothing is registered with a server until it serves
    registration_time_*_ms, registration_time_per_handler_ms@agent.traversal(name) for N handlers on an already-constructed Agent; the cost is dominated by deriving each handler's JSON input/output schema
    agent_memory_mean_mb, memory_per_handler_bytestracemalloc after a forced GC, Agent and handlers measured separately
    cold_start_*_msAgent plus one handler
    request_latency_*_us, theoretical_single_thread_rpsthe raw await handler(...) call, as the original measured
    local_call_latency_*_usagent.call_local(...): JSON input coercion, handler, output encoding, still no server

    analyze.py prints a comparison table for every suite in results/ and, with matplotlib installed, saves results/benchmark_summary.png.

    Optional baselines

    langchain_bench/ and crewai_bench/ create the equivalent number of tools in LangChain and CrewAI and emit the same JSON shape. They need langchain-core and crewai respectively (requirements.txt), call no model, and exit with a message when the library is missing.

    Differences from the original

    • atfgraph_server=/auto_register=False became graph_server=; a vNext Agent never registers implicitly.
    • @agent.reasoner(f"handler-{j}") became @agent.traversal(f"handler_{j}").
    • A second latency metric (agent.call_local) shows the SDK's binding cost on top of the raw call.
    • The Go and TypeScript SDK benchmarks, the Mastra baseline and the stored historical results/*.json were not migrated: those SDKs are retired and the stored numbers measured the previous runtime.

    Tests: tests/test_migrated_ops_examples.py runs the benchmark with small counts and the analyzer on its output.
