    README

    Rendered from examples/python/retrieval_basics/README.md; the source file is not modified.

    Persistent document ingestion, hybrid retrieval, cited answers and deletion. Text and local .txt/.md/.rst files are supported.

    Run locally

    From the atfgraph-vnext checkout, with its Python SDK installed in your active environment:

    atfg server start
EXAMPLE_MODE=fixture python -m atfgraph.worker --module examples.python.retrieval_basics.main:app
# In a second terminal:
python -m examples.python.retrieval_basics.call

    Or install and run the node as a managed local installation:

    atfg install ./examples/python/retrieval_basics
atfg run retrieval_basics

    The node.py entrypoint also works when this folder is copied out of the checkout. The graph server defaults to http://127.0.0.1:18880; inspect traversers and child calls at http://127.0.0.1:18880/ui/.

    Call with the CLI

    atfg traverse retrieval_basics.ingest_document --in '{"document_id": "desk", "text": "The travel desk opens at 9am."}'

    Providers

    EXAMPLE_MODE=fixture is the default: deterministic local example data and calculations, no model or search calls. Retrieval fixtures use token hashing, not a learned embedding model. Fixture scores demonstrate mechanics, not model quality.

    To use live model decisions, set EXAMPLE_MODE=live, ATFGRAPH_MODEL_URL, ATFGRAPH_MODEL_NAME and, when needed, ATFGRAPH_MODEL_API_KEY. Retrieval examples additionally require ATFGRAPH_EMBEDDING_URL (the full embeddings endpoint), ATFGRAPH_EMBEDDING_MODEL and optional ATFGRAPH_EMBEDDING_API_KEY. Configure these before starting the worker. Missing settings fail explicitly; live failures never silently fall back to fixture answers.

    Local document reads are restricted to EXAMPLE_DOCUMENT_ROOT, which defaults to this example folder. Only text, Markdown and reStructuredText are accepted, up to 1 MB per file. To index your documentation, set this root to the directory you want the worker to access. Folder ingestion accepts at most 100 files. Source text is untrusted data; generated prose requires review even when citation identifiers and quoted passages validate.

    Python client

    from atfgraph import Client

async with Client("http://127.0.0.1:18880") as client:
    result = await client.traverse(
        "retrieval_basics.ingest_document",
        {'document_id': 'desk', 'text': 'The travel desk opens at 9am.'},
        timeout=300,
    )
    print(result)

    After ingestion, ask and remove a document:

    atfg traverse retrieval_basics.answer_question --in '{"question":"When does the travel desk open?","top_k":3}'
atfg traverse retrieval_basics.forget_document --in '{"document_id":"desk"}'
