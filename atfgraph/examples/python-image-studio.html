    README

    Rendered from examples/python/image_studio/README.md; the source file is not modified.

    Run these commands from the atfgraph-vnext checkout. Install the authoring SDK and build the CLI once:

    python -m pip install -e ./python
cargo build --bin atfgraphd --bin atfg
export PATH="$PWD/target/debug:$PATH"
atfg server start

    The server defaults to http://127.0.0.1:18880; its browser UI is /ui/. Set ATFGRAPH_SERVER and ATFGRAPH_API_KEY for a different server.

    Configure a chat model using ATFGRAPH_MODEL_URL, ATFGRAPH_MODEL_NAME and ATFGRAPH_MODEL_API_KEY, plus IMAGE_MODEL and its image provider credentials (for example OPENAI_API_KEY). Requests may incur provider charges.

    python -m atfgraph.worker --module examples.python.image_studio.agent:app
# Another terminal:
atfg traverse image-studio.generate_artwork --in '{"topic":"An amber compass beside a travel journal","size":"1024x1024"}'
python -m examples.python.image_studio.call create_prompt '{"topic":"A quiet Bali beach at dawn"}'

    generate_artwork records two child steps: typed prompt expansion and image creation. The response includes prompt, style notes, provider model, URLs and saved inline image paths. Set ATFGRAPH_MEDIA_DIR on the worker to choose the local artifact directory (default /tmp/atfgraph-image-studio). URL-only images are returned without downloading them; saved paths belong to the worker host. Choose an image size/model your provider supports. This example never returns a fake image when a provider fails. Live provider access is required to generate artwork.
